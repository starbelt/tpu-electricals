# 3D Models

STEP (`.step`/`.stp`) models for the components used on `sb-tpu`, referenced by the footprints in [../footprints.pretty/](../footprints.pretty/) for 3D visualization and mechanical fit checks in KiCad's 3D viewer.

Sourced from component manufacturer/distributor libraries (e.g. LCSC/EasyEDA). If a footprint shows a missing 3D model, check that its footprint's 3D model path still matches a filename here — see the [Open Items](../../README.md#open-items) note about stale paths.
