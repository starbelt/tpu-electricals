# Production Backups

Timestamped snapshots (`sb-tpu_YYYY-MM-DD_HH-MM-SS.zip`) of the manufacturing exports in [../](../), taken at various points during the design's history. Each archive is a full copy of the production export at that point in time, not a diff.

These are historical artifacts kept for reference — the current design's manufacturing files always live one directory up in [../](../); prefer those over anything here unless you specifically need an older revision.
